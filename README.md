## 🚀 Project Overview

A business intelligence solution for Adidas to address underperformance in U.S. regions (South, Southeast, Midwest) by integrating CRM automation via Salesforce, data analytics with Python, and dynamic dashboards in Power BI.

---

## 🎯 Business Challenge

Adidas experienced:
- Low sales and loyalty in target regions
- Limited online engagement
- CRM campaigns lacking automation or personalization

---

## 🧠 Solution Highlights

- 🧩 Salesforce CRM workflows for loyalty-based customer segmentation
- 🐍 Python-based EDA & preprocessing
- 🗃️ PostgreSQL for centralized analytics backend
- 📈 Power BI dashboards for regional sales, CRM impact, and loyalty trends

---

## 🛠️ Technologies Used

| Tool            | Purpose                                |
|-----------------|----------------------------------------|
| Python (Pandas) | EDA and dataset preprocessing          |
| Power BI        | Interactive dashboards                 |
| PostgreSQL      | Scalable data storage and queries      |
| Salesforce CRM  | Loyalty-based campaign automation      |
